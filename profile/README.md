# AMR臨床リファレンスセンター
## AMR Clinical Reference Center（AMRCRC）

AMR臨床リファレンスセンター（AMRCRC）は、国立健康危機管理研究機構（Japan Institute for Health Security：JIHS）の国立国際医療センターに設置されているセンターです。

薬剤耐性（Antimicrobial Resistance：AMR）対策を推進するため、サーベイランス、医療機関・地域への支援、情報提供、教育・普及啓発、抗菌薬に関する疫学研究に取り組んでいます。

## センターについて

AMRCRCは、薬剤耐性（AMR）対策アクションプランに基づく取り組みを進めるため、2017年4月に厚生労働省委託事業として設立されました。

AMRに関する情報を広く収集・分析し、その結果を分かりやすく示すとともに、一般の方々や医療従事者に、AMR対策に必要な知識と学習機会を提供しています。

## 主な活動

### サーベイランスとデータの活用

医療関連感染症や抗菌薬使用量などに関するサーベイランスシステムを構築し、収集した情報をAMR対策に活用しています。

医療機関や地域が状況を把握し、対策を検討するための情報提供と地域連携の支援に取り組んでいます。

### 医療機関・地域への支援

サーベイランスで得られた情報を基に、医療機関同士の連携を支援しています。また、耐性菌アウトブレイク対策の実地支援に取り組んでいます。

### 医療従事者への教育・情報提供

学会・職能団体などと連携し、AMR対策に関するガイドライン・マニュアルの作成、研修会・セミナーの企画と実施、e-learningによる学習機会の提供を行っています。

抗菌薬の適正使用や感染対策について、医療現場で活用できる情報・資料を発信しています。

### 一般の方々への普及啓発

薬剤耐性や抗菌薬の適正使用について、ウェブサイトや啓発資材を通じて情報を発信しています。

医療従事者だけでなく、一般の方々にもAMRを身近な課題として理解していただけるよう、分かりやすい情報提供に取り組んでいます。

### 抗菌薬に関する疫学研究

抗菌薬に関する疫学研究を通じて、抗菌薬使用の実態や関連する課題を検討し、適正使用や薬剤耐性対策に資する知見の創出に取り組んでいます。
