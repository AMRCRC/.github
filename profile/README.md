# AMR臨床リファレンスセンター

AMR Clinical Reference Center（AMRCRC）

AMR臨床リファレンスセンター（AMRCRC）は、国立健康危機管理研究機構（Japan Institute for Health Security：JIHS）の国立国際医療センターに設置されています。

薬剤耐性（Antimicrobial Resistance：AMR）対策を推進するため、サーベイランス、医療機関・地域への支援、教育・情報提供、普及啓発、研究に取り組んでいます。

## センターについて

AMRCRCは、「薬剤耐性（AMR）対策アクションプラン」に基づく取り組みを進めるため、2017年4月に厚生労働省の委託事業として設立されました。

AMRに関する情報を収集・分析して分かりやすく発信するとともに、医療従事者や一般の方々に、AMR対策に必要な知識と学習の機会を提供しています。

## 主な活動

### サーベイランスとデータの活用

医療関連感染や抗菌薬使用量などのサーベイランスシステムを構築し、医療機関や地域が状況を把握して対策を検討できるよう、得られた情報を提供しています。

### 医療機関・地域への支援

サーベイランスで得られた情報を基に、医療機関同士の連携や地域連携を支援しています。また、医療機関や保健所の依頼を受けて、耐性菌アウトブレイク対策の実地支援を行っています。

### 医療従事者への教育・情報提供

学会・職能団体などと連携し、AMR対策に関するガイドライン・マニュアルの作成、研修会・セミナーの開催、e-learningによる学習機会の提供を行っています。

抗菌薬の適正使用や感染対策について、医療現場で活用できる情報・資料も発信しています。

### 一般の方々への普及啓発

薬剤耐性や抗菌薬の適正使用について、ウェブサイトや啓発資材を通じて情報を発信しています。一般の方々にもAMRを身近な課題として理解していただけるよう、分かりやすい情報提供に努めています。

### 研究

抗菌薬使用の実態や関連する課題を疫学的に検討し、抗菌薬の適正使用とAMR対策に役立つ知見の創出に取り組んでいます。
